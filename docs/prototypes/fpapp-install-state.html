Superseded FPApp install state model

REJECTED DESIGN RECORD. This throwaway page models the earlier A/B rollback idea. The implemented design uses four independent slots: a failed upload empties only its selected slot and the user uploads again. The live Configurator's Apps page now contains the testable Installed Apps section. This file is retained for design-history review and must not be treated as the current specification.

Start a Sift 1.1.0 update, lose power midway, and confirm Sift 1.0.0 remains active.

Commit a structurally valid Sift 1.1.0 that fails runtime validation at boot, then fall back to 1.0.0.

Put Sift in a layout and confirm update and removal are rejected until it is inactive.
