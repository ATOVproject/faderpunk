One CV in, three shaped outs. Each out is independently CV, Gate or Trigger: CV gets attenuverter / offset / slew, Gate and Trigger get threshold / hysteresis / pulse length. A long press on channels 1–3 cycles that out through CV → Gate → Trigger right on the device, and the change is stored as a parameter, so the configurator stays in sync. Shift + long press on an out cycles its output range; the button flashes once for ±5 V or twice for 0–10 V to confirm the new setting. Channel 0 freezes the conditioned input on a short tap; channels B/C/D mute on a short tap.

With nothing patched into the input, channel 0 turns into a morphing LFO and drives B/C/D on its own once the jack has been still for about 1.2 s — movement on the jack switches back to CV in. Same wave engine as Super LFO, with speed, morph and skew on the three channel 0 fader layers (Main = speed, Alt = morph, Third = skew) and Shift + short press for clock sync. *LFO Speed* moves the whole rate range down to Slow or Slowest.

All four waves — the conditioned input on channel 0 plus the three outs B, C and D — mirror to MIDI. Channel 0 and any out in CV mode always send CC. On Gate or Trigger outs, *Mode Map* can switch a lane to Note instead: one bit per out (B in bit 0, C in bit 1, D in bit 2); when set, that lane sends Note On/Off on edges and the pitch comes from that lane’s *CC Map* slot (7-bit note number). *Mode Map* 0 keeps every lane on CC (legacy). By default they share the base *MIDI Channel* and take *MIDI CC* + 0…3. *Ch Map* and *CC Map* break that up: *Ch Map* packs one nibble per wave (wave 0 in bits 0–3, wave 1 in bits 4–7, …), value + 1 = MIDI channel 1…16; *CC Map* packs 7 bits per wave (wave 0 in bits 0–6, wave 1 in bits 7–13, …) holding the CC number directly (or the note number when *Mode Map* selects Note for that lane). A map of 0 means “all waves follow the base”, which is the shipped default and bit-for-bit the old behaviour. Example: channels 1, 5, 9 and 13 → nibbles 0, 4, 8, 12 → 0 + 4·16 + 8·256 + 12·4096 = 51 264; CCs 20, 21, 40, 41 → 20 + 21·128 + 40·16384 + 41·2097152 = 86 641 300. A CC Map field is seven bits wide, so it reaches CC 0–127 only; in NRPN mode the base CC still spans the full 14-bit range, a mapped one does not.

LEDs use five equidistant hues running from blue through violet and red to orange, one per operating mode. Channel 0 is blue while CV in feeds the outs and one step warmer once the internal LFO takes over; the outs take the remaining three steps by mode — CV, then Gate, then Trigger in orange — so a mode swap is visible the moment it lands. All four channels dim with signal amplitude.
