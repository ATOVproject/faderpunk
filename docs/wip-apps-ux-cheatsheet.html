ID 29

Heat Pump ready

Clock-synced sidechain ducking envelope

Faders

  • Main — Release (up = faster recovery)
  • Alt — Duck depth (red LED)
  • Third — unused

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Depth · Release · Duck
  • Dest colors: Red · Yellow · Cyan
  • CV Att 0–100%

Buttons

  • Short — Manual duck trigger
  • Long — Mute / bypass (hold idle)
  • Shift+Short (CV Out) — Cycle clock division
  • Shift+Short (CV In) — Cycle CV Dest (flash)
  • Shift+Long — Invert duck direction

LEDs / other params

  • Button metronome Mid→Low per division
  • 1/1 uses Color param
  • Invert: white ↔ off fade
  • Color, Range, MIDI CH/CC, NRPN, MIDI Out

Manual. Clock-synced ducking envelope: each division pulse ducks, then recovers by Release. Depth sets how far. Mute bypasses so CV/MIDI stay at idle. Invert flips duck direction. With Jack=CV In, Shift+Short cycles Depth/Release/Duck instead of division; CV Att scales the modulation.

ID 30

Grooves ready

Multi-genre MIDI drum grooves with swing

Faders

  • Main — Density (extra hits)
  • Alt — Swing
  • Third — CV-jack activity mode: low=Any, high=Stacked

Genres

  • Dub → Disco → Hip-Hop → House → Techno → Trip-Hop → UK Garage → Dubstep

Buttons

  • Short — Reset to downbeat
  • Long — Mute (notes off)
  • Shift+Short — Reverse swing
  • Shift+Long — Cycle genre (flash)

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Density · Swing · Reset
  • Range, CV Att

Params

  • Kick / Snare / Hats: note + channel
  • Groove, Swing max %, GATE %, Color, MIDI Out

Manual. Genre MIDI drums on the global clock. Density reveals hits; Swing max % caps the Alt fader. Third picks how the CV Out jack reflects simultaneous hits (Any vs Stacked). Jack=CV In modulates Density/Swing or triggers Reset (set Dest in Configurator).

ID 31

Golden Gate ready

Fibonacci-spaced gates — ratios → φ

Faders

  • Main — Fibonacci depth
  • Alt — Cycle length N
  • Third — Speed: up=16th · mid=8th · down=quarter

Jack params

  • Jack: CV Out / CV In (In = MIDI-first, no outs)
  • CV Dest: Depth · Cycle · Reset
  • Range, CV Att

Buttons

  • Short — Reset to downbeat
  • Long — Mute
  • Shift+Short — Reverse gap direction
  • Shift+Long — Cycle out mode

Out modes

  • Gate+Note · Gate+CC (orange)
  • Pitch 12-TET (red) · Pitch φ (pink)

Params

  • MIDI CH/Note/CC, GATE %, Speed, Color, MIDI Out

Manual. Fills cycle length N with Fibonacci gaps; deeper sets approach φ. Short resets; Shift+Short reverses travel; Button+Fader sets local speed. Shift+Long cycles Note/CC/Pitch/φ. Jack=CV In drops CV/gate outs and uses Dest for Depth/Cycle/Reset.

ID 32

Super LFO ready

Morphing dual-osc LFO · 2 channels

Faders

  • Ch0 Main — Morph · Third — Skew
  • Ch1 Main — Character · Third — Warp
  • Alt — Speed (red when focused)

CV destinations (Ch0 Shift+Short)

  • Yel Speed · Pink Phase · Cyan Amp · Red Reset
  • Orange Morph · Violet Skew · Green Warp · Rose Character

Buttons

  • Ch0 Short — Freeze toggle (white)
  • Ch0 Long — In mute
  • Ch0 Shift+Short — Cycle CV Dest
  • Ch0 Shift+Long — Cycle Mix Mode
  • Ch1 Short — Phase reset
  • Ch1 Long — Out mute
  • Ch1 Shift+Short — Phase reverse

Params

  • Speed, Range, MIDI, Grid Lock
  • Mix Mode: Xfade / Min / Max / Sum
  • Osc B: Quad / Octave · Mix balance 0–100%

Manual. Dual-osc morphing LFO. Ch0 Morph/Skew, Ch1 Character/Warp, Shift+Fader = Speed. Ch0 jack CV Dest is cycled on device. Freeze holds the wave; In-mute silences CV-in; Out-mute silences output. Grid Lock ties phase to the clock when clocked.

ID 33

Echolot draft

MIDI/CV delay with feedback and pitch shift

Faders

  • Main — Delay (up = shorter / faster)
  • Alt — Feedback
  • Third — Pitch interval

Buttons

  • Short — Mute / ring-out
  • Long — Panic (clear queue); skipped if Third used this hold

LEDs

  • White flash on MIDI/gate in (~20% when muted)

Params

  • I/O: MIDI→MIDI · MIDI→CV · CV→MIDI
  • Delay: ms / Clock · Max delay
  • Interval: Fixed / Stack / Pong
  • Routing: Single / Ping-Pong
  • Signal: Pitch / Gate / CV→CC / Gate→Note
  • MIDI In/Out A/B, CC, Note, Range, Color

Manual. Delay with feedback and optional pitch intervals. Mute = ring-out (block new input; queue plays out). Long Panic clears the trail — Button+Fader Interval edits never panic that hold. MIDI In always flashes white for diagnosis when muted.

ID 34

Arp de Lévy ready

Lévy-flight arp — evolve, texture, flight character

Faders

  • Main — Evolve / mutation (0 = frozen)
  • Alt — Texture (density / phrase / swing feel)
  • Third — Lévy α / flight character

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Evolve · Texture · Reroll
  • Range, CV Att · V/Oct · Bypass quantizer

Buttons

  • Short — Reroll note pool (+ reset)
  • Long — Mute
  • Shift+Short — Reverse playback
  • Shift+Long — Cycle octave span 1→2→3→4

Octave LED

  • Blue · Cyan · Yellow · Red

Params

  • MIDI CH, Base Note, Color, MIDI Out
  • CV pitch + MIDI (dual path)

Manual. Generative arp whose pool evolves with Lévy-flight mutations. Main bottom freezes; raise to wander. Texture shapes phrase density/length; Third sets flight character (α). Shift+Long walks octave span (button color). Jack=CV In can modulate Evolve/Texture or fire Reroll.

ID 35

MIDI Vamp draft

Chord progressions — perform, capture, auto · MIDI

Faders

  • Main (Perform) — Scrub vamp slots
  • Main (Auto) — Tension
  • Alt — Genre (+ Capture clip slot if clip exists)
  • Third — Autoplay clock division

CV params

  • CV Dest: Macro · Panic · CV Att

Buttons

  • Shift+Button — Perform ↔ Auto
  • Perform hold — Chord on; release = off
  • Auto short — Play / pause
  • Perform Long — Capture last N bars → timed clip, jump Auto+Play
  • Auto Long — Clear clip, reload genre preset
  • Shift+Long — Panic

Params

  • Root, Scale, Genre, Voicing, Velocity
  • Auto style: Repeat / Meander
  • Start mode: Perform / Auto
  • Capture: 16 / 8 / 4 / 2 bars
  • LED: Perform = app color; Auto = orange (bright=play)

Manual. MIDI chord vamp. Perform: scrub + hold to play; Long captures a timed clip of recent harmony and arms Auto playback. Auto: short play/pause; Long clears the clip and reloads genre DNA. Alt picks genre (and Capture slot when a clip exists). CV Dest Macro modulates scrub/tension; Panic can fire from CV.
