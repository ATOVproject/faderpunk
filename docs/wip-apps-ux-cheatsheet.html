ID 29

Heat Pump ready

Clock-synced sidechain ducking envelope

Faders

  • Main — Release (up = faster recovery)
  • Alt — Duck depth (red LED)
  • Third — Clock division (1/1 … 1/32)

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Depth · Release · Duck
  • Dest colors: Red · Yellow · Cyan
  • CV Att 0–100%

Buttons

  • Short — Manual duck trigger
  • Long — Mute (freeze level; no snap to idle)
  • Shift+Short (CV In) — Cycle CV Dest (flash)
  • Shift+Long — Invert duck direction

LEDs / other params

  • Button metronome Mid→Low per division
  • 1/1 uses Color param
  • Invert: white ↔ off fade
  • Color, Range, MIDI CH/CC, NRPN, MIDI Out

Manual. Clock-synced sidechain duck: each division pulse drops to Depth, holds ~⅛ of the division, then log-shaped Release back to idle. Mute freezes the envelope (clock triggers discarded). Invert flips duck direction. Third (button+fader) sets division; Shift+Short cycles CV Dest when Jack=CV In. CV Att scales modulation.

ID 30

Grooves ready

Multi-genre MIDI drum grooves with feel

Faders

  • Main — Density (extra hits)
  • Alt — Genre morph (LED = red→blue spectrum)
  • Third — Feel (0 = flat/grid → max = accents + timing + swing)

Genres

  • Dub → Disco → House → Techno → Trip-Hop → Hip-Hop → Jungle → UK Garage → Dubstep
  • LEDs always follow genre spectrum (no Color param); Enum chrome still discrete
  • Morph: soft-lerp accents/timing/swing between neighbors; core masks from nearer genre
  • DNA: accent masks + microtiming; swing bias from shared groove module

Buttons

  • Short — Reset to downbeat
  • Long — Mute (notes off)
  • Shift+Short — Reverse swing
  • Shift+Long — Toggle jack Any ↔ Stacked (yellow/violet flash)

LEDs

  • Button / Top / Bottom = genre hue (red→blue spectrum)
  • Button Mid→Low blink on each hit

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Density · Feel · Reset (Configurator only)
  • Range, CV Att

Params

  • Kick / Snare / Hats: note + channel
  • Groove, Swing max % (Feel swing ceiling), GATE %, MIDI Out

Manual. Genre MIDI drums on the global clock. Density reveals fills; Shift+Fader is a continuous genre morph (park between neighbors blends feel DNA; core pattern snaps at midpoint). Button / bar LEDs always use the genre spectrum hue (like LFO has no Color param). Button Mid→Low blinks on hits. Button+Fader = Feel — attenuates accents, microtiming, and genre swing (capped by Swing max %). Feel bottom ≈ flat equal velocity / straight grid; top = full groove. Shift+Long toggles CV Out Any↔Stacked. Jack=CV In modulates Density/Feel or triggers Reset — set CV Dest in the Configurator only. CV Att scales input.

ID 31

Golden Gate ready

Fibonacci-spaced gates — ratios → φ

Faders

  • Main — Fibonacci depth
  • Alt — Cycle length N
  • Third — Local speed grid (16th → quarter; center = follow Speed param)

Jack params

  • Jack: CV Out / CV In (In = MIDI-first, no outs)
  • CV Dest: Depth · Cycle · Reset
  • Range, CV Att

Buttons

  • Short — Reset to downbeat
  • Long — Mute
  • Shift+Short — Reverse gap direction
  • Shift+Long — Cycle Mode (Note/CC/Pitch/Phi)

Mode param

  • Note · CC · Pitch (12-TET) · Phi (φ pitch)
  • Button color: default / orange / red / pink

Params

  • MIDI CH/Note/CC, GATE %, Speed, Color, MIDI Out

Manual. Fills cycle length N with Fibonacci gaps; deeper sets approach φ. Mode param selects Note/CC/Pitch/Phi; Shift+Long cycles the same on-device. Third overrides Speed locally. Short resets; Shift+Short reverses travel. Jack=CV In drops CV/gate outs and uses Dest for Depth/Cycle/Reset.

ID 32

Super LFO ready

Morphing dual-osc LFO · 2 channels

Faders

  • Ch0 Main — Morph (LED = red→blue spectrum) · Alt — Attenuation (Amp)
  • Ch0 Third — Skew
  • Ch1 Main — Symmetry · Alt — Speed
  • Ch1 Third — Phase-Warp

CV destinations (Ch0 Shift+Short)

  • Blue Rate Mod · Pink Phase · Red Reset · Cyan Amp
  • Yellow Speed · Orange Morph · Violet Skew
  • Green Warp · Rose Symmetry

Buttons

  • Ch0 Short — Freeze toggle (white)
  • Ch0 Long — In mute
  • Ch0 Shift+Short — Cycle CV Dest
  • Ch0 Shift+Long — Cycle Mix Mode
  • Ch1 Short — Phase reset
  • Ch1 Long — Out mute
  • Ch1 Shift+Short — Phase reverse
  • Ch1 Shift+Long — Clock sync toggle

Params

  • Speed, Range, MIDI, Grid Lock
  • Mix Mode: Xfade / Min / Max / Sum
  • Osc B: Quad / Octave · Mix balance 0–100%
  • Rate-mod depth 0–100% (Configurator) · CV Dest can modulate it
  • Ch0 jack = CV In · Ch1 jack = CV Out

Manual. Dual-osc morphing LFO. Ch0 Morph/Amp/Skew on CV In; Ch1 Symmetry/Speed/Warp on CV Out. Shift+Short on Ch0 cycles CV Dest. Freeze holds the wave; In-mute silences CV-in; Out-mute silences output. Ch1 Shift+Long toggles clock sync (Grid Lock). Mix balance 0–100% (Xfade only).

ID 33

Echolot draft

MIDI/CV delay with feedback and pitch shift

Faders

  • Main — Delay (up = shorter / faster)
  • Alt — Feedback
  • Third — Pitch interval (±24 st)

Buttons

  • Short — Mute / ring-out
  • Long — Panic (clear queue); skipped if Third used this hold

LEDs

  • White flash on MIDI/gate in (~20% when muted)
  • Ping-Pong: Top = Out A · Bottom = Out B

Params

  • I/O: MIDI→MIDI · MIDI→CV · CV→MIDI
  • Delay: ms / Clock · Max delay
  • Interval mode: Fixed / Stack / Bounce
  • Routing: Single / Ping-Pong
  • Signal: Pitch / Gate / CV→CC / Gate→Note
  • MIDI In/Out A, Out Pong, CC, Note, Range, Color

Manual. Delay with feedback and optional pitch intervals. I/O picks MIDI/CV routing; Ping-Pong alternates MIDI Out A/B (MIDI→MIDI and CV→MIDI). Mute = ring-out (block new input; queue plays out). Long Panic clears the trail — Third interval edits never panic that hold. MIDI In always flashes white for diagnosis when muted.

Arp de Lévy ready

Lévy-flight arp — evolve, texture, flight character

Faders

  • Main — Evolve / mutation (0 = frozen)
  • Alt — Texture (density / phrase / swing feel)
  • Third — Lévy α / flight character

Jack params

  • Jack: CV Out / CV In
  • CV Out source (Jack=Out): Pitch · Gate · Velocity
  • CV Dest (Jack=In): Evolve · Texture · Reroll
  • Range, CV Att · V/Oct · Bypass quantizer

Buttons

  • Short — Reroll note pool (+ reset)
  • Long — Mute
  • Shift+Short (CV Out) — Cycle CV Out source
  • Shift+Short (CV In) — Reverse playback
  • Shift+Long — Cycle octave span 1→2→3→4

Octave LED

  • Blue · Cyan · Yellow · Red

Params

  • MIDI CH, Base Note, Color, MIDI Out
  • CV pitch + MIDI (dual path)

Manual. Generative arp whose pool evolves with Lévy-flight mutations. Main bottom freezes; raise to wander. Texture shapes phrase density/length; Third sets flight character (α). Shift+Long walks octave span (button color). Jack=CV Out: Shift+Short cycles Pitch/Gate/Velocity. Jack=CV In: Shift+Short reverses; CV modulates Evolve/Texture or fires Reroll.

ID 35

Chord Vamp ready

Chord progressions — perform, capture, auto · MIDI + CV

Faders

  • Main (Perform) — Scrub genre degrees × 3 octaves (pitch map)
  • Main (Auto) — Tension (Meander only)
  • Alt — Genre morph (+ Capture clip slot if clip exists; Capture LED = rose)
  • Third (Auto) — Feel (laid ↔ advanced stab length)
  • Third (Perform) — Feel still stored; LEDs = blue / chord pitch

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Macro · Panic
  • Range, V/Oct, CV Att

Buttons

  • Perform hold — Chord on; release = off (blue LEDs track pitch)
  • Auto short — Play / pause
  • Shift+Short (Perform) — Auto (capture if ring has chords)
  • Shift+Short (Auto) — Return to Perform
  • Auto Long — Clear clip, reseed genre phrase
  • Shift+Long (Auto) — Panic

Params

  • Root, Scale, Genre, Voicing, Velocity
  • Auto style: Repeat / Meander
  • Start mode: Perform / Auto
  • Capture: 16 / 8 / 4 / 2 / 1 bars
  • LED: Perform = app color; Auto = orange; Hold Auto = rose (phrase pos)

Scene storage

  • 8-slot vamp + Capture clip
  • Swing 0–100 — morphs between neighbor genre biases while parked; reseeds structure only on nearest-genre change
  • Feel, scrub, tension, mode, play/pause

Manual. MIDI chord vamp with optional CV jack. Perform: fader = genre-unique degrees ascending across ~3 octaves; hold plays the chord (blue = pitch). Shift+Short enters Auto (and captures recent harmony into a timed clip when the ring has chords; empty ring = genre phrase Auto). Auto: genre rhythm phrase loops — multi-chord statement (~1–2 bars) then multi-bar rest; harmony Repeat or Meander; Feel sets short stab gate (rests fixed); Swing delays odd 16ths — Shift+Fader morphs swing bias between neighbors without reseeding; crossing the midpoint reseeds phrase/slots once. Alt LED = red→blue spectrum (Capture slot stays rose). Short = play/pause; Long clears clip / reseeds; Shift+Short → Perform. CV Macro = scrub/tension; Panic from CV optional.

ID 36

Hold Sam ready

Clocked sample & hold → MIDI Note/CC

Faders

  • Main (Note) — Gate length (% of current division)
  • Main (CC) — Output amount (sample → CC)
  • Alt — Clock division
  • Third (Note) — Velocity sensitivity from CV delta
  • Third (CC) — unused

Jack

  • CV In — signal to sample (pitch / CC source)
  • Config Attenuverter applied before sample

Buttons

  • Short — Soft mute (ausklingen; no new events)
  • Shift+Short — Manual sample (+ Note/CC)
  • Long (no fader move) — Hard Note Off + mute on
  • Long + Fader — Third layer only (no panic)

Transport

  • Stop — like soft mute; gate finishes via timer
  • Reset — phase only; sample/note kept
  • Always retrigger on tick (even same pitch); monophonic cut

Params

  • MidiMode Note/CC, Channel, CC #, Color
  • Range, MidiOut, V/Oct, Bypass quantizer
  • Attenuverter (0–4095, 4095 = unity)
  • Base Velocity 1–127

LEDs

  • Button = app color Mid; Low while note gated / brief CC duck (off when muted)
  • Top = note/CC activity (velocity brightness)
  • Bottom = active latch value (Main/Alt/Third)

Manual. Clocked S&H bridge: each division tick samples CV In (after Config Att) and sends MIDI. Note mode: cut+retrigger with vel = base + sens × |ΔCV|; Main = gate % of the division. CC mode: Main = amount. Soft mute and Stop let the sounding note finish; Long without fader move is panic. Shift+Short samples off the clock. Global clock source (Internal / MIDI / one Aux); Aux divisions are just patchable outs into the jack if you want.

ID 37

Harmonica ready

Monophonic MIDI/CV harmonizer

Faders

  • Main — Chord type (Unison → Power → min → maj → Sus4 → min7 → Dom7)
  • Alt — Voicing spread (lift harmony in octave steps)
  • Third — Harmony velocity (root keeps input vel)

Jack

  • MIDI→CV: highest sounding pitch out
  • CV→MIDI: root pitch in (quiet→Armed; motion then stable→play)
  • MIDI→MIDI: unused

Buttons

  • Short — Mute harmony only (root keeps sounding)
  • Shift+Short — Cycle harmony octave −1 → 0 → +1
  • Long — Panic (all notes this app owns)
  • Long + Fader — Third layer only (no panic)

I/O

  • MIDI→MIDI / MIDI→CV / CV→MIDI
  • Templates chromatic; non-root tones snap to global scale (bypass = chromatic)
  • Live revoice as fader moves

Params

  • I/O, Range, Color
  • MIDI In / In CH / Out / Out CH
  • 1V/Oct, Bypass quantizer

LEDs

  • Top = chord type / pitch (red on Alt or Third)
  • Bottom = octave (−1 dim, 0 mid, +1 bright); velocity on Third

Manual. Builds a chord from a single root. Fader picks chord type; Alt opens the voicing; Third sets harmony velocity. Mute affects harmony only. Shift+Short cycles harmony octave. CV→MIDI arms silent on quiet float; after ADC motion the next stable pitch plays (stepped CV / Note Fader friendly). Long panics every note this app owns.
