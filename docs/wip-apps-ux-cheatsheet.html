ID 29

Heat Pump ready

Clock-synced sidechain ducking envelope

Faders

  • Main — Release (up = faster recovery)
  • Alt — Duck depth (red LED)
  • Third — Clock division (1/1 … 1/32)

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Depth · Release · Duck
  • Dest colors: Red · Yellow · Cyan
  • CV Att 0–100%

Buttons

  • Short — Manual duck trigger
  • Long — Mute (freeze level; no snap to idle; dim red button)
  • Shift+Short (CV Out) — Cycle clock division
  • Shift+Short (CV In) — Cycle CV Dest (flash)
  • Shift+Long — Invert duck direction

LEDs / other params

  • Button metronome Mid→Low per division · Mute = dim red (not off)
  • 1/1 uses Color param
  • Invert: white ↔ off fade
  • Color, Range, MIDI CH/CC, NRPN, MIDI Out

Manual. Clock-synced ducking envelope: each division pulse ducks, then recovers by Release. Depth sets how far. Mute freezes the envelope at its current level (clock triggers discarded). Invert flips duck direction. Third sets division directly; Shift+Short cycles division (CV Out) or CV Dest (CV In). CV Att scales modulation.

ID 30

Grooves ready

Multi-genre MIDI drum grooves with swing

Faders

  • Main — Density (extra hits)
  • Alt — Genre scrub (same colors as Chord Vamp)
  • Third — Swing (capped by Swing max %)

Genres

  • Dub → Disco → House → Techno → Trip-Hop → Hip-Hop → Jungle → UK Garage → Dubstep
  • Colors (shared w/ Vamp): Orange · Yellow · Pink · Cyan · Violet · Red · Lime · Green · Blue
  • Alt scrub LEDs: continuous IR→UV spectrum (not discrete genre chrome)

Buttons

  • Short — Reset to downbeat
  • Long — Mute (notes off)
  • Shift+Short — Reverse swing
  • Shift+Long — Toggle jack Any ↔ Stacked (yellow/violet flash)

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Density · Swing · Reset (Configurator only)
  • Range, CV Att

Params / LEDs

  • Kick / Snare / Hats: note + channel
  • Groove, Swing max %, GATE %, Color, MIDI Out
  • Button Main: genre hue sat half→full (density) + bar lightness; hit dips kick −50% / snare −30% / hats −10%
  • Button Third: White→Color→Red (swing); same voice-weighted hit dips
  • Button Alt: committed genre hue (Top/Bottom = live fader meters; color changes only after latch pickup)

Manual. Genre MIDI drums on the global clock (9 shared genres with Chord Vamp, including Jungle). Density reveals hits; Shift+Fader scrubs genre on the shared axis — button hue follows the latched genre (meters show live fader until pickup); Button+Fader = Swing (capped by Swing max %). Watch the button: Main density ramps genre hue from half→full saturation with bar lightness; hits dim by voice (kick −50%, snare −30%, hats −10%) — not a clock blink. MIDI fires outside the clock subscriber (pending_* isolate). Third swing blends White→app→Red. Shift+Long toggles CV Out Any↔Stacked. Jack=CV In modulates Density/Swing or triggers Reset — set CV Dest in the Configurator only. CV Att scales input.

ID 31

Golden Gate ready

Fibonacci-spaced gates — ratios → φ

Faders

  • Main — Fibonacci depth
  • Alt — Cycle length N
  • Third — Local speed grid (16th → quarter; center = follow Speed param)

Jack params

  • Jack: CV Out / CV In (In = MIDI-first, no outs)
  • CV Dest: Depth · Cycle · Reset
  • Range, CV Att

Buttons

  • Short — Reset to downbeat
  • Long — Mute
  • Shift+Short — Reverse gap direction
  • Shift+Long — Cycle Mode (Note/CC/Pitch/Phi)

Mode param

  • Note · CC · Pitch (12-TET) · Phi (φ pitch)
  • Button color: default / orange / red / pink

Params

  • MIDI CH/Note/CC, GATE %, Speed, Color, MIDI Out

Manual. Fills cycle length N with Fibonacci gaps; deeper sets approach φ. Mode param selects Note/CC/Pitch/Phi; Shift+Long cycles the same on-device. Third overrides Speed locally. Short resets; Shift+Short reverses travel. Jack=CV In drops CV/gate outs and uses Dest for Depth/Cycle/Reset.

ID 32

Super LFO ready

Morphing dual-osc LFO · 2 channels

Faders

  • Ch0 Main — Morph · Alt — Attenuation (Amp)
  • Ch0 Third — Skew
  • Ch1 Main — Symmetry · Alt — Speed
  • Ch1 Third — Phase-Warp

CV destinations (Ch0 Shift+Short)

  • Blue Rate Mod · Pink Phase · Red Reset · Cyan Amp
  • Yellow Speed · Orange Morph · Violet Skew
  • Green Warp · Rose Symmetry

Buttons

  • Ch0 Short — Freeze toggle (white)
  • Ch0 Long — In mute
  • Ch0 Shift+Short — Cycle CV Dest
  • Ch0 Shift+Long — Cycle Mix Mode
  • Ch1 Short — Phase reset
  • Ch1 Long — Out mute
  • Ch1 Shift+Short — Phase reverse
  • Ch1 Shift+Long — Clock sync toggle

Params

  • Speed, Range, MIDI, Grid Lock
  • Mix Mode: Xfade / Min / Max / Sum
  • Osc B: Quad / Octave · Mix balance 0–100%
  • Rate-mod depth 0–100% (Configurator) · CV Dest can modulate it
  • Ch0 jack = CV In · Ch1 jack = CV Out

Manual. Dual-osc morphing LFO. Ch0 Morph/Amp/Skew on CV In; Ch1 Symmetry/Speed/Warp on CV Out. Shift+Short on Ch0 cycles CV Dest. Freeze holds the wave; In-mute silences CV-in; Out-mute silences output. Ch1 Shift+Long toggles clock sync (Grid Lock). Mix balance 0–100% (Xfade only).

ID 33

Echolot draft

MIDI/CV delay with feedback and pitch shift

Faders

  • Main — Delay (up = shorter / faster)
  • Alt — Feedback
  • Third — Pitch interval (±24 st)

Buttons

  • Short — Mute / ring-out
  • Long — Panic (clear queue); skipped if Third used this hold

LEDs

  • White flash on MIDI/gate in (~20% when muted)
  • Ping-Pong: Top = Out A · Bottom = Out B

Params

  • I/O: MIDI→MIDI · MIDI→CV · CV→MIDI
  • Delay: ms / Clock · Max delay
  • Interval mode: Fixed / Stack / Bounce
  • Routing: Single / Ping-Pong
  • Signal: Pitch / Gate / CV→CC / Gate→Note
  • MIDI In/Out A, Out Pong, CC, Note, Range, Color

Manual. Delay with feedback and optional pitch intervals. I/O picks MIDI/CV routing; Ping-Pong alternates MIDI Out A/B (MIDI→MIDI and CV→MIDI). Mute = ring-out (block new input; queue plays out). Long Panic clears the trail — Third interval edits never panic that hold. MIDI In always flashes white for diagnosis when muted.

ID 34

Arp de Lévy ready

Lévy-flight arp — evolve, texture, flight character

Faders

  • Main — Evolve / mutation (0 = frozen)
  • Alt — Texture (density / phrase / swing feel)
  • Third — Lévy α / flight character

Jack params

  • Jack: CV Out / CV In
  • CV Out source (Jack=Out): Pitch · Gate · Velocity
  • CV Dest (Jack=In): Evolve · Texture · Reroll
  • Range, CV Att · V/Oct · Bypass quantizer

Buttons

  • Short — Reroll note pool (+ reset)
  • Long — Mute
  • Shift+Short (CV Out) — Cycle CV Out source
  • Shift+Short (CV In) — Reverse playback
  • Shift+Long — Cycle octave span 1→2→3→4

Octave LED

  • Blue · Cyan · Yellow · Red

LEDs

  • Button / Top — latch hue + level: Main = Color/Evolve · Alt = Orange/Texture · Third = Violet/α; mute = off
  • Bottom — Pitch height in Color while gated (note activity)

Params

  • MIDI CH, Base Note, Color, MIDI Out
  • CV pitch + MIDI (dual path)

Manual. Generative arp whose pool evolves with Lévy-flight mutations. Main bottom freezes; raise to wander. Texture shapes phrase density/length; Third sets flight character (α). Shift+Long walks octave span (button color). Jack=CV Out: Shift+Short cycles Pitch/Gate/Velocity. Jack=CV In: Shift+Short reverses; CV modulates Evolve/Texture or fires Reroll.

ID 35

Chord Vamp ready

Chord progressions — perform, capture, auto · MIDI + CV

Faders

  • Main (Perform) — Scrub genre degrees × 3 octaves (pitch map)
  • Main (Auto) — Tension (Meander only)
  • Alt — Genre (+ Capture clip slot if clip exists)
  • Shared axis: Dub → Disco → House → Techno → Trip-Hop → Hip-Hop → Jungle → UK Garage → Dubstep
  • Third (Auto) — Feel (laid ↔ advanced stab length)
  • Third (Perform) — Feel still stored; LEDs = blue / chord pitch

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Macro · Panic
  • Range, V/Oct, CV Att

Buttons

  • Perform hold — Chord on; release = off (blue LEDs track pitch)
  • Auto short — Play / pause
  • Shift+Short (Perform) — Capture last N bars → Auto+Play
  • Shift+Short (Auto) — Return to Perform
  • Auto Long — Clear clip, reseed genre phrase
  • Shift+Long (Auto) — Panic

Params

  • Root, Scale, Genre, Voicing, Velocity
  • Auto style: Repeat / Meander
  • Start mode: Perform / Auto
  • Capture: 16 / 8 / 4 / 2 / 1 bars
  • LED: Perform = app color; Auto = orange; Hold Auto = rose (phrase pos)

Scene storage

  • 8-slot vamp + Capture clip
  • Swing 0–100 — genre-seeded; odd-16th delay (no Configurator param)
  • Feel, scrub, tension, mode, play/pause

Manual. MIDI chord vamp with optional CV jack. Shared 9-genre axis with Grooves (Dub→…→Jungle→…→Dubstep). Perform: fader = genre-unique degrees ascending across ~3 octaves; hold plays the chord (blue = pitch). Shift+Short captures recent harmony (starts quantized to 16ths, lead-in cropped to first hit; hold lengths free) into a timed clip and arms Auto. Auto: genre rhythm phrase loops — multi-chord statement (~1–2 bars) then multi-bar rest; harmony Repeat or Meander; Feel sets short stab gate (rests fixed); Swing (scene, genre-seeded) delays odd 16ths on Auto + Capture. Short = play/pause; Long clears clip / reseeds; Shift+Short → Perform. Alt = genre (+ Capture slot). CV Macro = scrub/tension; Panic from CV optional.

Harmonica ready

Monophonic root in → chord MIDI out

Faders

  • Main — Chord type
  • Alt — Spread / voicing width
  • Third — Velocity

Buttons

  • Short (no fader move) — Mute / unmute all voices
  • Alt+Short — Cycle harmony octave (−1 / 0 / +1)
  • Alt+Long — Step voicing preset

Params

  • I/O: MIDI / CV root; MIDI In/Out CH

  • Strum (ms), Color, Range, V/Oct
  • Near-0V CV = rest; unpatched stays silent until stable pitch

ID 38

Loop de Cay ready

Additive overdub loop with level decay

Faders

  • Main — Pitch (span from Base Note); spectrum LED meter
  • Alt (Shift+Fader) — Decay: bottom = immortal, top ≈ 4 loops to silence (violet→red)
  • Third (muted + hold button + fader) — Loop length 1–8 bars (amber→cyan)

Buttons

  • Hold (gate modes) — Note on; release = off (long notes OK)
  • Shift+Short — Arm / disarm record (button blinks when armed; default armed)
  • Shift+Long — Mute (red LED; decay pauses)
  • Short while muted — Unmute
  • Shift+Long while muted — Erase buffer (white flash)

Params / LEDs

  • Mode: Pitch→MIDI · Gate→MIDI · MIDI→MIDI · MIDI→CV · Fader→Both
  • MIDI CH / In / Out, Base Note, Span (semitones across fader)
  • Color, Range, V/Oct
  • Capture/playback hit: sharp button 80% dim (~2 PPQN) + Top white; layer meters on Top/Bottom/Button

Manual. Clocked overdub loop: play while armed to capture; layers decay each loop wrap by Alt amount (0 = freeze forever; max ≈ 4 wraps). Hold the button for long notes — mute is Shift+Long only. Length is Third while muted (not Alt). Velocity uses a squared curve so fades are audible on MIDI. Quantized to 16ths.

ID 39

Control Issues ready

Shape CV and send it as MIDI CC / NRPN

Faders

  • Main — Attenuverter −100…+100 % (center deadband = 0)
  • Alt (Shift+Fader) — Offset −100…+100 %
  • Third (hold button + fader) — Slew 0…10 s

Buttons

  • Short click (no fader move) — Mute toggle on release (sends Output Min)
  • Hold + fader — edit Slew (suppresses mute)
  • Shift+Hold — momentary Bypass (keeps Range / Min-Max / Rate)

Params / LEDs

  • Pipeline: Gate/CV → Att → Offset → Transfer → Slew → Steps → Min/Max → Rate
  • Button LED only: Main = app color × out; Alt = red × |offset|; Third = cyan × slew (floor so hue stays visible at 0)
  • Mute = off · Bypass = full · black blink on downbeat while out > Min

Manual. 1-channel CV→MIDI sculptor. Defaults are transparent (+100 % att, 0 offset, 0 slew, Linear, full CC window, 100 Hz). Gate mode runs a Schmitt threshold (0.1 V hysteresis) then the same pipeline. Mute sends Output Min once and goes silent; unmute resends the live value. Watch the button LED for level — fader LEDs stay dark. Uses clock ticker only (no CLOCK_PUBSUB). No clock → no downbeat blink.

ID 40

Venn ready

Dual Euclidean layers + boolean logic (OR/AND/XOR/Accnt)

Faders

  • Main — F0 pulses A · F1 pulses B
  • Alt (Shift) — F0 rotation A · F1 rotation B
  • Third (Btn1 or Btn2 hold) — F0 length A · F1 length B (2–32)

Buttons

  • Btn1 or Btn2 hold — Third (length A/B on F0/F1)
  • Btn2 tap (no fader move) — Mute both outs
  • Shift+Btn1 — Cycle Logic OR → AND → XOR → Accnt
  • Shift+Btn2 — Toggle post-logic invert (shadow); white↔none fade like Heat Pump

Params / LEDs

  • Division, GATE %, Prob %, Vel %, MIDI CH / Notes / Out, Color
  • Color = Layer A; Btn2 / Top B = fixed complement (Cyan↔Pink, Blue↔Orange, Green↔Violet, Rose↔Yellow, …)
  • Main Btn: logic hue / complement · density bright · soft hit dip (−38% → 62%)
  • Alt: Top+Btn ∝ rotation (floor); Bottom = step-0 sync · Third: white Top ∝ length, Bottom/Btn = length band (live 1 ms)
  • Top flashes = layer hits (Main) · Bottom flashes = logic outs (Main)
  • Jack0 = logic result · Jack1 coupled (OR→∩, AND→△, XOR→∩, Accnt→accent)

Manual. Two independent Euclidean masks combined with boolean logic — the OXI GEN dual-layer idea without pitch. Color sets Layer A; Layer B LEDs use a fixed complement (always the same pairs). Btn1 shows logic mode, not Color. Different lengths per layer enable polyrhythmic XOR/AND patterns Euclid cannot make alone. Needs clock. Prob % < 100 adds optional flakiness; 100 is fully deterministic. No pitch CV (use GenSeq for that).
