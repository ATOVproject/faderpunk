ID 31

Golden Gate ready

Fibonacci-spaced gates — ratios → φ

Faders

  • Main — Fibonacci depth
  • Alt — Cycle length N
  • Third — Local speed grid (16th → quarter; center = follow Speed param)

Jack params

  • Jack: CV Out / CV In (In = MIDI-first, no outs)
  • CV Dest: Depth · Cycle · Reset
  • Range, CV Att

Buttons

  • Short — Reset to downbeat
  • Long — Mute
  • Shift+Short — Reverse gap direction
  • Shift+Long — Cycle Mode (Note/CC/Pitch/Phi)

Mode param

  • Note · CC · Pitch (12-TET) · Phi (φ pitch)
  • Button color: default / orange / red / pink

Params

  • MIDI CH/Note/CC, GATE %, Speed, Color, MIDI Out

Manual. Fills cycle length N with Fibonacci gaps; deeper sets approach φ. Mode param selects Note/CC/Pitch/Phi; Shift+Long cycles the same on-device. Third overrides Speed locally. Short resets; Shift+Short reverses travel. Jack=CV In drops CV/gate outs and uses Dest for Depth/Cycle/Reset.
