ID 36

Hold Sam ready

Clocked sample-and-hold — Note or CC

Faders

  • Main — Gate % (Note) or CC amount (CC mode)
  • Alt — Clock division
  • Third — Velocity / sensitivity

Buttons

  • Short — Play / trigger held sample
  • Shift+Short — Manual sample (capture now)
  • Long (no fader move) — Soft mute (fade; no hard note-off)

Params / LEDs

  • Mode Note / CC, MIDI CH/CC, Color, Range, V/Oct
  • Layer meters: IR→UV spectrum on Main/Alt/Third fader
  • White flash on each sample; mute = red button

Manual. Clocked sample-and-hold. Capture on division or Shift+Short; Main shapes gate length or CC depth. Long soft-mutes so notes can ring out. Third sets how strongly velocity follows the sample.
