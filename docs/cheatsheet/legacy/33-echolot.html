Echolot draft

MIDI/CV delay with feedback and pitch shift

Faders

  • Main — Delay (up = shorter / faster)
  • Alt — Feedback
  • Third — Pitch interval (±24 st)

Buttons

  • Short — Mute / ring-out
  • Long — Panic (clear queue); skipped if Third used this hold

LEDs

  • White flash on MIDI/gate in (~20% when muted)
  • Ping-Pong: Top = Out A · Bottom = Out B

Params

  • I/O: MIDI→MIDI · MIDI→CV · CV→MIDI
  • Delay: ms / Clock · Max delay
  • Interval mode: Fixed / Stack / Bounce
  • Routing: Single / Ping-Pong
  • Signal: Pitch / Gate / CV→CC / Gate→Note
  • MIDI In/Out A, Out Pong, CC, Note, Range, Color

Manual. Delay with feedback and optional pitch intervals. I/O picks MIDI/CV routing; Ping-Pong alternates MIDI Out A/B (MIDI→MIDI and CV→MIDI). Mute = ring-out (block new input; queue plays out). Long Panic clears the trail — Third interval edits never panic that hold. MIDI In always flashes white for diagnosis when muted.
